# Gifts That Grow — free GitHub Pages website

This folder contains a complete one-page family gifting website.

## Before publishing

1. Open `index.html` in a text editor.
2. Replace **Grandchild One** and **Grandchild Two** with the children's names.
3. Add the two photos to the `images` folder:
   - `grandchild-1.jpg`
   - `grandchild-2.jpg`
4. The Venmo recipient is already set to **@tutu3290**.
5. Optionally edit any of the wording in `index.html`.

## Publish for free with GitHub Pages

1. Create a free GitHub account at github.com if you don't already have one.
2. Create a new repository. A name such as `gifts-that-grow` works well.
3. Upload:
   - `index.html`
   - `styles.css`
   - the entire `images` folder
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Save.

GitHub will provide a public address similar to:

`https://YOUR-GITHUB-NAME.github.io/gifts-that-grow/`

You can text or email that address to family members and reuse it all year.

## Privacy note

Because a GitHub Pages site is public, avoid posting the children's last names, birthdays, school names,
home address, or other identifying information. First names and carefully selected photos are usually
better for a family gift page.

## Custodial-account wording

The page intentionally says the gifts will be moved to a custodial investment account and kept invested
for the child's future. If you are using a specific UTMA/UGMA structure, you may want to have your tax or
legal adviser review the wording because custodial-account rules and tax consequences can vary.
